# params.json に足したい定数

`params.json` は書き換えていない。センサ層が必要とする定数のうち、いま `params.json` に
無いものを `sensors/virtual.py` の `ADDED_DEFAULTS` に既定値として持っている。
**この表をそのまま `params.json` に取り込めば、`ADDED_DEFAULTS` は空にできる。**

寸法から見積もった値であって、実機の実測値ではない。source 欄はその計算過程。

---

## sensors.accel_lf（架台の柱、DC 結合 MEMS）

| キー | 値 | 単位 | 根拠 |
|---|---:|---|---|
| `frame_equiv_mass_kg` | 60.0 | kg | 下記 A |
| `structure_freq_hz` | 250.0 | Hz | 下記 B |
| `structure_damping` | 0.03 | - | 下記 B |
| `structure_model` | `"grounded"` | - | 下記 C |

### A. 架台の等価質量 60 kg

センサを付ける柱まわりで、水平に一緒に動く質量。ステンレスの角パイプ 4 本と天板で見積もる。

```
柱   80x80x3.2 角パイプ、高さ 0.75 m
     断面積 A = (80^2 - 73.6^2) = 983 mm^2 = 9.83e-4 m^2
     1 本   9.83e-4 * 0.75 * 7900 = 5.82 kg  → 4 本で 23.3 kg
     水平 1 次モードでの有効質量は 1/3 ほどなので 7.8 kg
天板 600 x 600 x 12 のステンレス板  0.6*0.6*0.012*7900 = 34.1 kg
駆動部（減速機・軸受箱・カップリング）          およそ 15 kg
--------------------------------------------------------
合計 7.8 + 34.1 + 15 = 57 kg  → 60 kg を採用
```

### B. 構造共振 250 Hz / 減衰比 0.03

センサ取付部の局所モード。柱の板（板厚 3.2 mm）の、溶接どうしの間 0.25 m を
両端固定はりと見て、

```
f = (22.37 / (2*pi*L^2)) * sqrt(E*I/(rho*A))
  I/A = t^2/12 = (0.0032^2)/12 = 8.533e-7 m^2
  sqrt(E/rho * t^2/12) = sqrt(193e9/7900 * 8.533e-7) = 4.566
  f = 22.37/(2*pi*0.0625) * 4.566 = 260 Hz  → 250 Hz を採用
```

減衰比 0.03 は、ボルト締め・溶接構造の一般的な水準（1〜3 %）の上側。
参考までに、架台全体の水平揺れモードは同じ寸法から 78 Hz（柱 4 本を両端拘束の
はりとして k = 12EI/L^3、質量 60 kg）。**共振は 1 つだけ入れる決まり**（SENSORS.md 3 節）なので、
衝撃が鳴るほうの局所モードを採った。全体モードのほうを採るなら 78 Hz に差し替える。
その場合の違いは demo.py が数字で出す。

### C. 取り付け部の伝達モデル

`"grounded"`（既定）は、架台を床に固定された構造とみなして、力から加速度への伝達を
2 次系のアクセレランス `s^2/(s^2 + 2*zeta*wn*s + wn^2)` にしたもの。
共振より下では加速度が `f^2` で落ちる（静的には力が変位になるだけで、加速度は出ない）。

`"free"` にすると直流利得 1 の 2 次系になり、低周波でも `a = F/m` がそのまま出る。
自由な剛体の仮定で、接地を無視した見方。

**この選択で「加速度センサでスロッシングが見えるか」の答えが 70 dB 変わる。**
既定は物理的に素直な `"grounded"` にしてあるが、記事に書くときは
どちらを置いたかを明示すること（demo.py が両方の数字を出す）。

## sensors.accel_hf（軸受箱、交流結合の圧電）

| キー | 値 | 単位 | 根拠 |
|---|---:|---|---|
| `frame_equiv_mass_kg` | 25.0 | kg | 軸受箱・軸受支持部まわりの等価質量。天板を含まず、軸受箱（鋳鉄相当 12 kg）と支持ブラケット・軸端で 25 kg と置いた |
| `structure_freq_hz` | 1200.0 | Hz | 軸受箱は柱より硬い。板厚 12 mm・スパン 0.225 m の局所モードとして B と同じ式で 1200 Hz |
| `structure_damping` | 0.04 | - | 鋳物＋ボルト締結。柱より少し高めに置いた |
| `structure_model` | `"grounded"` | - | 上記 C と同じ |

軸受の衝撃（`impulse_accel_m_s2`）は加速度そのものとして与えられるので、この伝達は通さず
直接足す。この 2 次系が効くのは、テーブルの水平反力から来る連続成分のほうだけ。

## sensors.strain（テーブル支持軸の根元）

| キー | 値 | 単位 | 根拠 |
|---|---:|---|---|
| `arm_length_mm` | 150.0 | mm | 力点（テーブル面）から根元（軸受箱の固定端）までの距離 |
| `shaft_outer_diameter_mm` | 45.0 | mm | 中空丸軸の外径 |
| `shaft_inner_diameter_mm` | 39.0 | mm | 同 内径（肉厚 3 mm） |
| `youngs_modulus_GPa` | 193.0 | GPa | ステンレス（SENSORS.md 3 節の指定値） |
| `gauge_angle_deg` | 0.0 | deg | 感度方向。センサ方位（世界角 0）の半径方向を 0 とする |
| `rotating_gauge` | false | - | 下記 |

断面係数（`sensors/virtual.py` の `section_modulus_mm3` が同じ式で計算する）:

```
Z = pi*(D^4 - d^4)/(32*D) = pi*(45^4 - 39^4)/(32*45) = 3899 mm^3 = 3.899e-6 m^3
```

ひずみの感度:

```
strain = F * L_arm / (Z * E)
       = F * 0.150 / (3.899e-6 * 193e9) = 1.99e-7 * F  [strain/N]
       = 199 ustrain / kN
```

レンジ 500 ustrain は横荷重 2.5 kN 相当。実際に出るのは 0.5 N 程度なので、
レンジは 3 桁以上余っている（その代わり分解能は 24 bit で確保する形）。
強度側は、軸荷重（テーブル 30 kg で 300 N / 断面 396 mm^2 = 0.8 MPa）も
曲げ（横荷重 10 N なら M = 1.5 N·m、M/Z = 0.4 MPa）も、材料の許容に対して 2 桁以上余裕がある。

`rotating_gauge = false` は、ゲージを**静止側**（軸受箱・支持部）に貼る前提。
テーブルと一緒に回る軸に貼るならスリップリングか無線が要り、感度方向も回るので、
既定は静止側にした。`true` にすると感度方向が `th_t` と共に回る。

## 気づいた点（params.json 側で直したほうがよさそうなもの）

1. **`sensors.current.sample_rate_hz` = 4000 は、実際のログ周波数より速い。**
   `sim.log_rate_hz` は 4000 の指定だが、コアは `dt` の整数倍に丸めるので
   実際は `1/(13*2e-5)` = 3846.15 Hz（core/FORMAT.md 6 節）。
   センサ側が 4000 Hz だと、連続量を補間で埋めることになる（害は小さいが、
   何もしていないつもりで補間が入るのは気持ちが悪い）。
   `sim.dt_s` を 2.5e-5 にすれば 1/10 でちょうど 4000 Hz になる。

2. **`fill.source` の記述が古い**（「停止時間1.0s に収まる」とあるが、
   いまの停止時間は `tact - index_time` = 0.9 s）。充填 0.05+0.80=0.85 s なので
   収まってはいる。

3. `faults.bearing_outer_race.impulse_accel_m_s2` は、ヘッダに入っていないので
   CLI `--bearing-accel` で上書きするとセンサ層からは分からない。
   ヘッダに 1 つ足してもらえると、イベント列の振幅をログだけから決められる。
